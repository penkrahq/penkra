penkra tabs list
List retained App tabs in the caller's folder and Space.

How to use this operation

Use the exact returned tab ID for semantic observation and interaction. A retained tab remains readable when another tab is visible. visible reports whether the tab is currently shown. Each row contains tabId, appId, appName, title, status and visible, plus url only for a hosted web page. Activate before interacting.

Examples

  List retained App tabs

  {
    "command": "penkra tabs list"
  }

Input fields
  This operation has no named input properties.

Invocation
  Send one ordinary command string. Pass each input field by name exactly as listed
  under Input fields (for example --thread-id <id>). A bare value without its --name
  is rejected. Use --input "{...}" to pass the complete input as one JSON value.
  --input   Complete JSON operation input validated against the schema below.

Operating manual
