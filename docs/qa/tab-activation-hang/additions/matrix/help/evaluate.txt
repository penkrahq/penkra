penkra tabs evaluate
Evaluate JavaScript in one App-tab document.

How to use this operation

The expression runs in exactly d1 or d2 and returns its serializable value.

Examples

  Read the title

  {
    "command": "penkra tabs evaluate --tab-id <tab-id> --document d1 --expression 'document.title'"
  }

Input fields
  --document <string>  required; one of "d1", "d2". d1 addresses the App document; d2 addresses its hosted page, when present.
  --expression <string>  required.
  --tab-id <string>  required. Exact retained App tab ID returned by penkra tabs list.

Invocation
  Send one ordinary command string. Pass each input field by name exactly as listed
  under Input fields (for example --thread-id <id>). A bare value without its --name
  is rejected. Use --input "{...}" to pass the complete input as one JSON value.
  --input   Complete JSON operation input validated against the schema below.

Operating manual
  Run penkra tabs --help for Tabs operating instructions.

Validated input schema
{
  "type": "object",
  "properties": {
    "tabId": {
      "type": "string",
      "minLength": 1,
      "description": "Exact retained App tab ID returned by penkra tabs list."
    },
    "document": {
      "type": "string",
      "enum": [
        "d1",
        "d2"
      ],
      "description": "d1 addresses the App document; d2 addresses its hosted page, when present."

    "expression": {
      "type": "string"

  "required": [

    "document",
    "expression"
  ],
  "additionalProperties": false
}

  "type": "object"
}
