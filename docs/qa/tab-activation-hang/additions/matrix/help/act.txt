penkra tabs act
Run an ordered sequence of actions against d1 and d2.

How to use this operation

Act accepts steps through --input. Activate the tab and take a fresh snapshot first; inactive interaction fails before dispatch. A failed sequence reports completed steps and whether the failing step was dispatched. Element actions use d1:/d2: references from snapshot; --human true uses an eased visible cursor path. Upload targets a file input reference and accepts local file paths; absolute paths use the desktop filesystem and relative paths use the App's storage directory.

Examples

  Click and wait

  {
    "command": "penkra tabs act --input '{\"tabId\":\"<tab-id>\",\"steps\":[{\"action\":\"click\",\"ref\":\"d1:e3\"},{\"action\":\"wait\",\"document\":\"d1\",\"text\":\"Saved\"}]}'"
  }

Input fields
  --steps <array>  required.
  --tab-id <string>  required. Exact retained App tab ID returned by penkra tabs list.
  --human <boolean>  optional.

Invocation
  Send one ordinary command string. Pass each input field by name exactly as listed
  under Input fields (for example --thread-id <id>). A bare value without its --name
  is rejected. Use --input "{...}" to pass the complete input as one JSON value.
  --input   Complete JSON operation input validated against the schema below.

Operating manual
  Run penkra tabs --help for Tabs operating instructions.
