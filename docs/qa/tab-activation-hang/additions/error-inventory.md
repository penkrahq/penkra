# Authored tab error inventory

Each row audits one authored source site/template. **True** means the reported failure matches a native reproduction. **False** means its claim/code is contradicted by one. **Ambiguous** means incomplete runtime coverage, a broad formatter, or wording that conflates different states. Shared parser branches are a superset: some cannot be reached with the current tab schemas. They are retained so the audited surface is explicit.

Source paths and line numbers refer to a0a576730. This inventory includes errors propagated through selection/presentation, the socket gateway, observation and upload validation. It excludes unrelated App installation/operation/developer commands and the observer find API, which has no agent-facing tabs command. Transport OS errors, filesystem errors, arbitrary evaluate exceptions, Chromium/CDP errors, renderer failure strings and ffmpeg stderr form an unbounded family; their wrappers and observed instances are covered below, not purportedly every possible external string.
