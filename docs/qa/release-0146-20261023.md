# Penkra 0.14.6

## Release notes

- Videos play inline with standard playback controls. Multiple videos and mixed
  image/video attachments share the same gallery layout and navigation.
- Other file attachments use Open through Penkra's normal resource-opening path.
- Assistant message timestamps stay hidden while their turn is running.
- Opening Saved prompts no longer blanks the right-side App panel.
- Restoring Saved prompts and editing queued messages wait for the current draft
  to persist. Failed draft saves no longer masquerade as successful saves, and
  newer edits remain protected.

### Provider runtimes

Unchanged from 0.14.5:

- Codex CLI 0.163.0.
- Claude Code 2.1.307; Claude Agent SDK 0.3.307.
- OpenCode CLI and SDK 1.19.3.

### Windows distribution

The Windows x64 installer remains unsigned and manual-download only. Windows
auto-updates remain disabled. Verify downloads using SHA256SUMS.txt and GitHub's
build-provenance attestation.
