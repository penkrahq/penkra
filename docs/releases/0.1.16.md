# Penkra 0.1.16

- Discovers the Claude model catalog from the installed Claude Code runtime before a chat starts,
  so newly available models no longer require a Penkra catalog update.
- Persists Claude's canonical model identities instead of rewriting evergreen aliases such as
  `opus` through an older static compatibility entry.
- Uses runtime-discovered effort, adaptive-thinking, and fast-mode capabilities for future Claude
  models while retaining the static catalog as a conservative startup fallback.
- Displays canonical model labels such as Claude Opus 5 and honors a configured custom Claude
  executable path during discovery.
- Retains the Penkra 0.1.15 backend CLI revision because this release changes only the desktop
  server and web client.
