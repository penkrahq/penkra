# Penkra 0.1.4

- Restores differential macOS updates using a blockmap generated from the final verified ZIP.
- Removes an unused bundled Claude platform binary while continuing to use the installed Claude CLI.
- Makes routine internal releases ZIP-only and adds a timed local build, publish, and install path.
- Makes GitHub quality and release workflows manual-only to stop automatic hosted-runner spending.
- Surfaces a bounded error if a completed transfer never becomes ready to install.
- Corrects Penkra author and copyright metadata.

The inherited Synara package version is upstream baseline metadata; Penkra desktop releases use
the version declared in `scripts/penkra-release.json`.
