# Penkra 0.1.15

- Integrates the complete Synara v0.6.0 implementation as the new base, then reapplies Penkra's
  client isolation, instructions, skills, todos, private updater, and macOS-only product behavior.
- Adds Project Spaces, cross-task references, stronger task recovery, provider improvements, and
  the full upstream desktop and interface refinements without enabling rejected Synara Automations
  or External MCP surfaces.
- Restores the pending Penkra sidebar work: circular client avatars with badges open a Profile panel
  on the right, and choosing another client updates that same panel.
- Bundles the accepted backend CLI revision with operator-provisioned mobile identities, durable
  pg-boss queue recovery, frozen approval execution, and duplicate-safe channel delivery handling.
- Includes the completed Penkra client, organization, SDK operation, approval, Telegram, storage,
  and scoped database command surfaces.
- Ships as one signed native-arm64 ZIP with its verified blockmap and authenticated differential
  update feed; no DMG, Claude sidecar, staging build, or partial intermediate release is included.
