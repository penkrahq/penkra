# Penkra 0.1.12

- Keeps the instruction experience in the existing right dock and ordinary file viewer. The HQ
  icon opens the on-disk `hq.md` and `client.md` projections as separate tabs; a client icon opens
  only that client's on-disk `client.md`. No dialog, sheet, sliding sidebar, new control, animation,
  or custom viewer was added.
- Adds one app-wide filesystem watcher for project workspaces. External edits, reconciliation, and
  git changes now refresh open files and Explorer state without relying on agent-turn activity.
- Removes the obsolete remote-only instruction-pane read path while preserving remote records as
  authoritative and the workspace files as derived, read-only projections.
- Pins backend `6405602`, containing the production-migrated sandbox, gateway, channel, mobile, S3,
  and developer-verb platform bundle plus safe update-credential rotation support.
- Retains signed native-arm64 packaging, authenticated S3 updates, and differential downloads.
