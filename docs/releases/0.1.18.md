# Penkra 0.1.18

- Removes the overall voice-note audio duration limit and records long notes as bounded rolling WAV
  chunks.
- Transcribes chunks sequentially, retries only the failed chunk, and prevents cancelled or stale
  transcriptions from being inserted into the composer.
- Uses overlapping audio and normalized word/character matching to merge chunk boundaries without
  clipped or repeated phrases.
- Retains a reproducible 9-minute long-form audio fixture for on-demand Penkra Dev QA without adding
  the live transcription check to routine CI.
- Fixes pinned outbound DNS lookup compatibility with current Node and Electron runtimes.
- Retains the existing 120,000-character final user-turn limit and the Penkra 0.1.17 backend CLI.
