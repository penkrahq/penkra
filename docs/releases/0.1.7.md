# Penkra 0.1.7

- Shows live HQ, generic-client, and client-specific instruction documents from the backend through
  read-only Markdown viewers on Penkra sidebar rows.
- Keeps client-specific instructions editable through the remote API, supports intentional empty
  values, removes the old length cap, and no longer sends instruction bodies in app snapshots.
- Materializes blank instruction documents safely and preserves generic/client provenance without
  rewriting unchanged workspace files.
- Pins the production backend migration and client-schema isolation guard with disposable end-to-end
  coverage and scoped pre-migration recovery artifacts.
- Includes the restored top-right panel toggle and all changes shipped since `0.1.6`.
- Exercises the S3-compatible single-range differential updater from the installed `0.1.6` client.
