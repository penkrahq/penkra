# Penkra 0.1.14

- Bundles the accepted backend CLI revision with unified client keys, contextual approvals,
  pg-boss execution, JSON-only CLI output, and the production mobile-auth/device-registration
  fixes.
- Keeps HQ and client instructions as ordinary read-only Markdown files in the existing file
  viewer, with no bespoke notes UI.
- Preserves the existing desktop layout and top-right sidebar toggle.
- Fixes local workspace startup to launch the desktop repository and makes Windows Store editor
  icon discovery resilient to normal PowerShell startup time.
- Ships as one signed native-arm64 ZIP with its verified blockmap and authenticated differential
  update feed; no DMG, Claude sidecar, staging build, or partial intermediate release is included.
