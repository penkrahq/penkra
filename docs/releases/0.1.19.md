# Penkra 0.1.19

- Fixes Find getting stuck on “Searching…” after opening a new thread in Penkra Dev.
- Makes transcript, tool output, browser, diff, PDF, sidebar, terminal, and profile-pane results
  searchable without allowing one slow surface to block the complete result set.
- Adds bounded per-surface search deadlines and progressive result updates.
- Keeps Find registration alive through React Strict Mode's development remount checks.
- Signs the macOS app and all nested helpers with Penkra's Developer ID identity so macOS can
  recognize subsequent builds as the same application.
