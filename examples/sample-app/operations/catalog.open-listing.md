# Opening an App listing

Use this operation to navigate to one exact registry listing without installing it. Pass the
canonical reverse-domain App ID, such as `com.penkra.canvas`; a slug, display name, or registry row
ID is not interchangeable. Resolve the exact ID from the user or an authoritative operation result
instead of constructing it by pattern.

Opening a listing changes visible App state only. It does not install, update, enable, or grant
permissions. If the ID does not resolve, report that exact result or obtain the correct canonical ID
rather than guessing a nearby App.
